# 계약 현황

프론트가 의존하는 크로스파트 계약이 **어디까지 확정됐고 무엇을 기다리는지** 한곳에 모은 문서다.

이 문서의 목적은 다음 작업자와 에이전트가 원본 문서 여섯 개를 다시 읽지 않고도
무엇이 정해졌는지 알게 하는 것이다. **규약의 본문은 여기가 아니라 원본에 있다.**
값이 어긋나면 원본이 진실이다.

- 기준일: 2026-08-20 (FE-5 개정)
- 참조 원본
  - 공통 API 규격 v0.3 — 백엔드 파트 산출물(태스크 0-5). `apiSpec v0.1`보다 **우선한다**
  - [`docs/api/apiSpec.md`](../../docs/api/apiSpec.md) — 백엔드 API 명세 v0.1 (초안)
  - [`docs/spec/featureSpec.md`](../../docs/spec/featureSpec.md) — 기능 명세서 v2.1
  - [`ai/docs/openapi.json`](../../ai/docs/openapi.json) — **AI 서버의 실제 구현 스키마.** AI 파트 문서보다 이쪽이 사실이다
  - [`ai/docs/api-spec.md`](../../ai/docs/api-spec.md) — AI 파트 인터페이스 계약
  - AI 파트 회신 (2026-08-20, 4문항)
- 관련 규약: [`docs/convention/frontConvention.md`](../../docs/convention/frontConvention.md) (크로스파트) ·
  [`frontConvention.md`](./frontConvention.md) (프론트 내부) · [`ia.md`](./ia.md) (화면 목록)

**이 문서는 확정 / 잠정 확정 / 미확정 / 충돌의 네 단계를 쓴다.**
잠정 확정은 회신이 없어 프론트가 임의로 정하고 진행하는 것이다. 확정이 아니다.
**팀 회신이 오면 그 값이 우선하고 잠정 확정 항목은 폐기한다.**

### C3이 뒤집은 것

이전 판은 "`POST /chat`과 `POST /stocks/{ticker}/analysis`가 SSE이고 `EventSource`가 GET 전용이라
`fetch` + `ReadableStream` + `TextDecoder`로 직접 파싱한다"를 프론트의 핵심 제약으로 다뤘다.
**커밋 `34ed34a`에서 스트리밍이 설계에서 폐기됐고, `openapi.json`에도 `text/event-stream` 응답이 하나도 없다.**
`shared/api`에 스트림 파서를 만들지 않는다. 되살리려면 AI 파트 구현을 먼저 확인한다.

## 2. 잠정 확정 — 프론트가 임의로 정한 것

**전부 잠정이다.** 백엔드 회신이 오면 그 값이 우선한다.
근거가 얇은 것도 있지만, **고칠 범위가 작은 쪽을 골랐다.** 되돌리는 비용이 보이지 않으면 잠정으로 정하지 않는다.

충돌 **9건**. 이 중 X6·X7·X8이 이번 개정에서 새로 발견한 것이다.

### 이 충돌들의 공통 원인

**`apiSpec v0.1`이 공통 API 규격 v0.3의 확정 내용을 아직 반영하지 않았다.**
개별 항목을 프론트 문서에서 계속 예외 처리하기보다 **apiSpec을 v0.3 기준으로 갱신하는 쪽이 맞고,
그것은 백엔드 파트 소유 문서이므로 프론트가 고치지 않고 보고만 한다.**

다만 **엔드포인트 경로는 apiSpec 11장이 v0.3보다 최신이다**(X8). 문서 하나를 통째로 우선할 수 없으므로
항목별로 판단했고, 그 판단 근거를 위 표에 남겼다.

### 그 외 관측한 것

- **AI 서버에는 6종 외에 `POST /feedback`, `GET /wiki`, `POST /wiki/theses`, `PUT /wiki/theses/{ticker}`, `DELETE /wiki/facts/{fact_id}`가 구현돼 있다.** MVP 6종에 포함되지 않았고 화면 배치도 정해지지 않았다. 피드백 수집은 AI 슬롯 품질 측정에 쓰일 수 있으므로 범위 밖인지 확인이 필요하다
- **로그아웃 엔드포인트가 생겼다.** 이전 판에서 "명세에 없다"고 적었던 항목이 apiSpec §2.3 `POST /api/v1/auth/logout`으로 채워졌다. 마이페이지에서 호출한다
- **커서 페이징 `size` 예시가 어긋난다.** v0.3은 기본 30인데 apiSpec §8.2 예시는 `size=20`이다. 프론트가 값을 명시해 보내면 되므로 블로커는 아니다
