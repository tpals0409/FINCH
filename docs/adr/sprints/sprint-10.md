# Sprint 10 — 시세가 움직이는 화면

_기간: 2026-09-08 16:01 ~ 18:17 KST_

## 목표

1M/3M/1Y 일봉 데이터를 AI에서 백엔드로 적재하고 종목 상세 화면에 캔들 차트를 띄운다.
동시에 핫셋을 1종목에서 30종목으로 늘려 거래 가능 범위를 확대하고 처리량·페이싱·
`[S0-3]` 임계를 정규장에서 실측한다.

## 결정 사항

### D1. 파트는 자기 코드만 읽고 계약과 로그로 연결한다

Leo의 지시에 따라 AI는 `ai/**`, 백엔드는 `backend/**`와 백엔드 소유 API 명세,
프론트는 `frontend/**`만 읽고 수정한다. 교차 파트 구현을 읽는 대신 PR 본문의 정확한 JSON 계약을
인계면으로 삼고, 장애 추적은 토큰·사용자 정보를 제외한 구조화 로그로 한다.

### D2. 프론트는 백엔드 완료를 기다리지 않고 MSW로 병렬 구현한다

캔들 API의 공개 계약은 이미 `docs/api/apiSpec.md` §5.3에 있으므로, 프론트가 백엔드 구현을 읽거나
기다릴 이유가 없다. non-empty·empty·error를 MSW로 재현하고 실제 응답 연결만 후속 게이트로 남겼다.

### D3. FINCH는 Leo의 개인 ver2이고 저장소 등록 Git 신원을 공통 사용한다

에이전트별 Git 이름·이메일을 새로 만들지 않는다. 저장소에 등록된
`SeMin Kim <83855438+tpals0409@users.noreply.github.com>`을 author/committer로 사용하고,
담당 에이전트와 검증 근거는 Buzz 완료 보고와 PR 본문에 남긴다.

### D4. 완료되지 않은 핵심 목표를 숨기지 않고 스프린트를 닫는다

Leo가 18:17 KST에 종료를 승인했다. AI 경로만 master에 들어갔고, 백엔드·프론트와 핫셋 실측은
미완료다. 따라서 스프린트 상태는 종료하되 결과는 부분 완료로 기록하고 다음 스프린트로 이월한다.

## 인시던트

1. **완료 보고가 멘션 오류로 누락됐다.** Finch-mobile과 Finch-Front의 결과가 호출자에게 도착하지
   않았다. 공유 워크스페이스 파일과 워크트리 HEAD를 직접 읽어 결과를 회수했다.
2. **Git 귀속을 팀 프로젝트 방식으로 잘못 막았다.** 에이전트별 검증된 이메일을 요구해 AI PR과
   백엔드 커밋을 멈췄다. 루트 `CLAUDE.md`와 프로젝트 MEMORY는 처음부터 FINCH를 개인 ver2로
   명시했고, Leo가 이를 재확인해 공통 저장소 신원 규칙으로 차단을 풀었다.
3. **프론트 완료를 PR 완료로 오해할 뻔했다.** 실제 워크트리에는 커밋이 있었지만 GitHub PR은
   0건이었다. 독립 검증에서 feature 내부 경로 직접 import도 발견해 공개 경계로 수정했다.
4. **첫 프론트 재검증이 `TS5033 EPERM`으로 실패했다.** 코드 실패가 아니라 심링크 바깥 워크트리의
   TypeScript 캐시 쓰기를 샌드박스가 막은 것이었다. 같은 전체 검사를 권한이 있는 환경에서 다시
   실행해 36 tests와 모든 검사를 통과시켰다.
5. **PR #83 머지 명령의 로컬 브랜치 삭제만 실패했다.** AI 워크트리가 브랜치를 사용 중이어서
   삭제할 수 없었지만, PR은 `58c3efe`로 정상 머지됐다. 머지 상태를 별도로 재조회해 구분했다.

## 교훈

- **완료는 보고가 아니라 산출물과 원격 상태로 확인한다.** 멘션이 실패해도 공유 워크트리와 PR 조회로
  복구할 수 있다. 반대로 커밋이 있어도 PR이 없으면 CI·머지 단계는 끝난 것이 아니다.
- **프로젝트 정체성을 먼저 읽고 귀속 규칙을 적용한다.** 개인 ver2에 팀 프로젝트의 에이전트별 신원
  전제를 가져와 작업을 막았다. 루트 브리핑과 프로젝트 MEMORY가 이 판단의 선행 조건이다.
- **환경 실패와 코드 실패를 분리한다.** 같은 검사라도 샌드박스 쓰기 권한 때문에 실패할 수 있다.
  오류 코드와 경로를 읽고 권한이 있는 동일 환경에서 재실행한 결과만 코드 판정에 쓴다.
- **부분 완료를 완료로 포장하지 않는다.** 스프린트를 닫아도 미머지·미배포·미실측은 다음 행동과 함께
  이월해야 다음 세션이 같은 사실을 다시 조사하지 않는다.
