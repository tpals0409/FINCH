# Sprint 12 — 스프린트 재개

## 목표

이월된 운영 검증과 모바일 셸 작업을 재개하고, 장애 관측·검색 랭킹·시세 갱신·시세 폴링의 판정 근거를 남긴다.

## 범위

이번 스프린트의 범위는 다음 이슈다.

- #102 — KIS 실패 로깅
- #103 — 토큰 갱신 여유와 재시도 예산
- #101 — 모바일 셸 PR 및 APK 내용 검증
- #96 — UX writing
- #58 — 시세 폴링
- #87 — `price_daily` 갱신

## 이월

다음 항목은 이전 스프린트에서 이월되어 이번 스프린트에서 추적한다.

- #78 — 30종 핫셋 투입, 처리량·페이싱·S0-3 실측
- #90 — 운영 postgres-ai 지연 원인과 CPU 보장분 검증
- #93 — 운영 로그 필드명 관련 회귀와 관측성 확인

## 판정 기준

각 범위 항목은 해당 파트의 코드·문서·운영 검증 결과를 근거로 판정한다.

- 구현 항목은 관련 PR이 열리고 CI가 해당 커밋에서 성공해야 한다.
- KIS 실패 로깅은 실패 응답의 원인과 실제 운영 로그 출력이 확인되어야 한다.
- 검색 랭킹 변경은 동일 질의 세트의 top-5 문서 집합과 순서를 변경 전후로 비교해야 한다.
- 모바일 셸은 빌드 종료 코드뿐 아니라 생성된 APK의 `assets/public/` 내용을 확인해야 한다.
- 시세 폴링은 목록과 주문 화면의 요구 주기를 만족하는 주입 가능한 설정과 실측 근거가 있어야 한다.
- `price_daily`와 핫셋·postgres-ai 항목은 갱신 또는 성능 개선을 운영 관측으로 확인해야 한다.
- 결과, 수치, 커밋과 검증 출력은 작업이 끝난 뒤 이 문서에 기록한다.
